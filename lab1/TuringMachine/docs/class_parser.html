Detailed Description

Класс-парсер для чтения конфигурации машины Тьюринга из текстовых строк.

Отвечает за валидацию формата правил, проверку наличия состояний и символов в алфавите перед добавлением их в программу. Используется в интерактивном режиме main.cpp.
