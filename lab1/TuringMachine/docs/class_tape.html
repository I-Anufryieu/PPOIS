Detailed Description

Класс, представляющий ленту машины Тьюринга.

Лента реализована на базе двусвязного списка (std::list<char>) с итератором каретки. Позволяет хранить произвольные символы алфавита, динамически расширяться при выходе за границы и эффективно перемещаться в обе стороны.
