Detailed Description

Класс, реализующий исполнительную логику машины Тьюринга.

Управляет лентой, текущим состоянием, алфавитом и таблицей переходов. Метод step() выполняет один такт работы согласно программе.

◆ step()

bool TuringMachine::step ( )

Выполнить один шаг машины Тьюринга.

Ищет переход для пары (current_state, tape.get_symbol()). Если переход найден: записывает new_symbol, двигает голову, меняет состояние. Если не найден: возвращает false (остановка).

Returns
true, если шаг выполнен успешно и можно продолжать, false если остановка.
